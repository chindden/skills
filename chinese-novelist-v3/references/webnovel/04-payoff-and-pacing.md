# 爽点、阅读回报与节奏规划库

> 本库强调「期待—积累—兑现—后果—新期待」，不把每三章高潮或每十章反转列为硬规则。审稿频率是工程安排，高潮频率是故事需要，两者不能混同。

## 阅读回报分类
| ID | 回报类型 | 读者期待 | 需要的因果铺垫 | 失效信号 |
|---|---|---|---|---|
| Q01 | 能力兑现 | 训练/机缘终于派上用场 | 先看到限制、准备和尝试 | 胜利完全依赖临时新能力 |
| Q02 | 资源兑现 | 长期投入转化为装备、财富或栖身处 | 资源稀缺、分配与竞争 | 物资无限增长而不改变局面 |
| Q03 | 地位认可 | 被轻视者以行动改写评价 | 误判有理由，见证者有价值 | 路人每章重复震惊 |
| Q04 | 智斗胜利 | 对手也聪明，主角仍找到破局方法 | 双方目标、可见信息和错误判断 | 对手突然变蠢 |
| Q05 | 情感确认 | 双方付出选择，关系向前 | 各自独立目标与隐瞒成本 | 一句表白解决长期冲突 |
| Q06 | 悬念揭示 | 旧谜团得到可回溯解释 | 公平线索、可排除假说 | 只靠新人物口述真相 |
| Q07 | 生存安全 | 危机解除，准备终于有效 | 风险真实、逃生并非零代价 | 险境从未带来损失 |
| Q08 | 逆袭反差 | 低估被推翻，权力关系变化 | 轻视者动机可信、反差可证实 | 同一批路人反复挑衅 |
| Q09 | 探索发现 | 新地域、文化、规则拓宽世界 | 先设未知与探险动机 | 只有景观，没有新选择 |
| Q10 | 道德选择 | 两个有价值的目标无法兼得 | 双方诉求成立且后果明确 | 作者强塞完美第三条路 |
| Q11 | 团队成长 | 合作形成新的整体能力 | 成员有分歧与互补性 | 团队只为主角喝彩 |
| Q12 | 生活修复 | 关系、家园或能力逐步恢复 | 创伤与时间成本可见 | 受损后立刻复位 |

## 节奏规划的三种基本形态
- **快速反馈型**：开局尽快让读者看到主角优势与一项阶段收获；适合部分爽文、系统与都市题材，但同一招不可无限重复。
- **积累爆发型**：较长铺垫→多层障碍→关键抉择→集中兑现→余波；适合凡人流、苟道、悬疑和情感关系，不能用“慢热”合理化长期零推进。
- **交替双线型**：A线行动升级，B线人物关系、认知或经营在间隙兑现；两线必须交叉改变彼此，不能独立灌水。

**参考跨度**：局部故事弧可以从约 2–5 章起草，中段重要转折可从约 8–15 章考虑；这只是帮助初次规划的参考范围，必须依章节字数、题材及情节因果调整。六章短篇不需要硬凑十章大高潮，百章长篇也不能机械复制相同周期。

## 故事弧节奏表（建议写入 01-大纲.md）
| 项目 | 必答问题 |
|---|---|
| 当前期待 | 读者最希望看到主角完成的具体事是什么？ |
| 对手与阻力 | 谁会主动阻止？主角必须牺牲哪种资源、关系或信念？ |
| 过程变化 | 本弧是否出现不同性质的行动（探索、谈判、学习、失败、合作、冲突）？ |
| 兑现证据 | 本弧结束时，具体解决了哪个旧问题？不是只又多开一个谜团 |
| 不可逆后果 | 人物、资源、地位、世界规则的哪个状态改变了？ |
| 回落/呼吸 | 高潮后谁来承受后果？可否安排关系或生活沉淀？ |
| 下一期待 | 新目标如何由旧结果自然生发？ |

## 追读承诺台账（建议）
将读者期待登记为「建立→推进→部分兑现→完成/转化」，并写明来源章节、预期回报类型和必要前因。承诺逾期并非自动错误，但必须解释读者仍有哪种实际收获；不要用章末钩子掩盖悬而未决的旧承诺。

## 结构风险探针
1. **假高潮**：声势变大，但主角没有选择，人物状态不变。
2. **只加债不还债**：连续揭开新秘密，旧问题始终停在“有人隐瞒”。
3. **疲劳三连**：三次皆“敌人轻视→主角反杀→围观震惊”，只换对手名字。
4. **机械反转**：每逢固定章数必出现背叛，前文却没有行为依据。
5. **高潮后无余波**：重大死亡或突破下一章被完全遗忘。
6. **单线过载**：连续说明设定/办手续/打斗，缺少另一种情绪回报。
7. **临时第三条路**：终局突然引入不付成本的完美解法，破坏此前道德选择。
8. **情绪滥用**：持续高压、悲壮或煽情，读者逐渐麻木。
9. **提前泄底**：最有价值的谜团揭开后，剩余故事没有独立驱动。

## 审稿提问
最近三章哪些旧承诺真正兑现？人物是否作出新选择？情绪高低是否有意义地变化？同一方法是否重复？哪一个场景删掉也不会改变后文？答案要引用正文与大纲事实，不凭模型主观“8.7 分”过关。
