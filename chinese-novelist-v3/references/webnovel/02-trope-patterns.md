# 桥段套路与流派机制库

> 「流派」通常指持续叙事习惯，「桥段」是一次具体情节的组织模式。重生、系统属于设定机制；苟道、反派流是视角/策略；打脸、反杀是情绪兑现。可以搭配，但不能把标签当故事。

## 流派选择（先决定主引擎）
| ID | 流派/套路族 | 核心阅读回报 | 长线驱动 | 典型失败 |
|---|---|---|---|---|
| P01 | 凡人流 | 弱者靠判断、积累与机缘成长 | 小优势滚成大资源，环境不断改变 | 主角永远靠运气捡宝 |
| P02 | 苟道流 | 对风险的识别、准备与回避 | 探测威胁→积蓄手段→选择出手窗口 | 只躲不行动，故事长期停滞 |
| P03 | 长生流 | 时间尺度与世界变迁 | 故人更替、承诺延续、知识累积 | 单纯跳时间，不改变主角选择 |
| P04 | 无敌流 | 优势、反差与掌控感 | 身份误认、非战斗难题、价值取舍 | 反复让弱者挑衅然后秒杀 |
| P05 | 反派/魔道视角 | 非典型立场和利益冲突 | 盟友交易、阵营代价、敌对群体也有目标 | 一味恶行，没有可理解目标 |
| P06 | 重生改命 | 信息领先、弥补遗憾与策略博弈 | 旧知识逐渐失效，偏离造成新局面 | 前世知识永远准确、人人照剧本走 |
| P07 | 穿越发展 | 认知错位、技能迁移与文化冲突 | 资源/技术应用的阻力与制度博弈 | 现代常识无成本碾压异世界 |
| P08 | 宗门/家族经营 | 从微小组织成长的复利感 | 招人、分工、技术、内斗、外敌 | 资源无限且成员没有私心 |
| P09 | 幕后布局 | 读者知道部分布局，期待后果 | 信息差管理、代理人偏差、组织摩擦 | 作者无限给主角开全知视角 |
| P10 | 扮猪吃虎 | 被低估→主动忍耐→关键时刻反差 | 隐藏理由、暴露成本、揭示时机 | 整本书复制“嘲讽—打脸” |
| P11 | 迪化流 | 他人误判与主角真实能力的张力 | 不同阵营误解互相放大、误判反噬 | 所有人长期低智且从不修正 |
| P12 | 末世囤货 | 提前筹备和资源配置的安全感 | 资源损耗、盟友分配、长期秩序 | 无限库存消除生存压力 |
| P13 | 副本闯关 | 规则破解、协作与阶段胜利 | 不同副本的玩法演化与总线索推进 | 只换怪物皮肤、主角成长清零 |
| P14 | 科举仕途 | 能力通过制度获得认可 | 学业→地方→朝堂，责任与利益扩张 | 所有考官和同僚都没有自主利益 |
| P15 | 追妻/情感修复 | 关系失衡到重新认知的情绪回报 | 真实行动改变信任，失去有后果 | 一句道歉重置伤害 |
| P16 | 种田日常 | 努力积累改变生活的踏实满足 | 周期、家庭、市场和自然风险 | 以采购清单代替故事 |

## 可复用的情节构型（仅作为素材）
| 代码 | 桥段 | 最低成立条件 | 何时兑现才有效 |
|---|---|---|---|
| B01 | 隐藏身份/实力揭示 | 隐藏有实际收益和暴露代价 | 揭示改变人物关系或敌方判断 |
| B02 | 低阶越级胜利 | 前文展示准备、规则漏洞或牺牲 | 胜利后力量格局改变，敌人会学习 |
| B03 | 失去资源后另辟路径 | 失去是真实的，替代方案需费力 | 找回主动权但不抹去旧代价 |
| B04 | 敌方阵营内部裂痕 | 反派内部目标不同且提前埋线 | 主角必须付出谈判成本 |
| B05 | 秘境/副本争夺 | 空间规则、竞争目标、风险明确 | 夺宝之外产生承诺、债务或敌人 |
| B06 | 误判反转 | 双方误判有信息依据 | 反转后人物更新认知，不再原样受骗 |
| B07 | 师徒关系逆转 | 教导、信任和利益长期积累 | 选择对双方命运产生不可逆后果 |
| B08 | 经营成果遭挑战 | 已展示投入和组织关系 | 保护与妥协迫使组织结构变化 |
| B09 | 功法突破付代价 | 瓶颈在早期明确、资源有限 | 破境改变战力与社会关系，不只是播报数字 |
| B10 | 命运旧账回收 | 曾经选择留下未结后果 | 回收改变主角对自己的看法 |

## 组合规则：一个主引擎，两种以内辅助机制
1. 先用一句话写出主引擎的**稳定循环**：主角需要什么→遇到谁的反制→靠什么行动→获得什么回报→付出什么代价。
2. 再加入辅助标签，必须解释它如何改变循环；不能只是多一个“设定装饰”。
3. 至少演示三个不同阶段的循环如何变形：初期学规则、中期掌握规则、后期规则被对手反用。
4. 同一次创意竞标里比较「主驱动力」是否不同，不接受只换系统名称或职业的伪差异。

### 可行搭配
- **凡人流＋苟道＋有限预测**：主角只知道某类风险而非未来全知；预测偶尔失准，迫使主角在安全和责任间选择。
- **家族经营＋重生＋权谋**：记忆能提示旧机会，但家族成员的独立利益让历史改变。
- **无敌流＋关系经营**：战斗无悬念，冲突转向承诺、身份与信任；需要足够真实的非战斗代价。
- **反派视角＋幕后布局**：行动不公开，代理人会背叛或曲解命令；读者同时理解对手反制。

### 冲突搭配警示
- **无敌＋越级反杀**：如果主角已无敌，所谓越级胜利缺乏紧张感；转为名望、价值或规则难题。
- **苟道＋高频主动挑衅**：主角性格与行为冲突；除非给出迫使其冒险的具体个人理由。
- **重生＋绝对预知＋零代价系统**：多重确定性降低期待；至少让信息可靠性、资源或关系承担限制。
- **扮猪吃虎＋每章暴露身份**：策略失去意义，必须设计持续保密的收益与长期暴露成本。

## 计划检查
每个拟采用桥段应注明：第一次出现的具体人物选择、局部兑现、反派如何学习、再次使用必须如何变形。相似桥段可以重现，但人物、代价和后果不能全是同一个公式。
