## 1. 产品目标与用户决策（已确认，不再反复讨论）

**核心目标**：帮助 Gemini 创作一本**让读者愿意持续读下去**的完整中文长篇网络小说，而不是产出形式无瑕、缺乏魅力的审稿合格文本。

四项产品原则：
1. **小说吸引力第一**：优先考察开篇吸引力、角色魅力、情绪张力、承诺兑现和持续追读意愿；关键因果和已确立硬规则是不可突破的底线。
2. **创作优先，完本精修**：非阻断瑕疵可记录并后移；硬伤不得后移，已传播或将传播的错误要及时截断；完本后启动独立精修，不重写已成功的作品。
3. **创作自由**：核心承诺和关键因果相对稳定，尚未发生的远期剧情允许滚动演化，保留惊喜与人物自然发展。
4. **独立实验、可对照回滚**：R3 不直接替代 R2，R2 作为稳定对照基线；新机制经实际创作/工程测试再升级默认。

**明确非目标**
- 不建设 6–7 个常驻 Agent 的全自动编辑部。
- 不引入完整经济模拟 DSL 或企图用代码裁决自然语言的文学因果。
- 不以自评分、审稿报告字数、无警告数宣称作品优秀。
- 不擅自将《仙门大掌柜》Revision 2 的 `awaiting_approval` 改成已批准。
- 不在未测量漏检/返工成本前直接取消逐章独审。

## 2. R3 产品架构与稳定边界

采用**两级冻结 · 滚动双环 · 完本精修**。

- **核心契约**（`corePlan`）：核心读者承诺、核心人物与硬规则、关键因果及终局必要条件。全书剧透故事梗概可保留，但不应把所有远期具体桥段意外锁入硬冻结区。
- **卷级滚动外环**（`volumeCheckpoints`）：当前卷在作者批准后产生检查点；未锁定的下一卷及更远卷保持可变。卷末结合已写正文、伏笔、人物火花重新细化下一卷。已批准卷不能静默改写。
- **创作反馈内环**：`--handoff` 精准取数 → 写稿 → 结构化检查 → 按严重性与处置时机反馈 → 定稿 → 更新事实、伏笔与叙事动能。编辑应保护好桥段，不为消除小瑕疵反复打断创作。
- **完本精修**：仅在完本后另起独立任务，对全书、账本及延期问题做定向修订与影响范围复核，并保留可恢复的原稿快照。

**两种变更性质、独立审批证据**：已批准的核心契约与当前卷检查点不可静默修改；未获批准的远期滚动区允许调整。已写正文由独立稿件 SHA-256/审核凭证保护。卷级与核心审批必须绑定真实用户消息及其批准范围，不因改变 Markdown 标题、拼接文件或修改元数据而绕过。

## 6. 关键规则：缺陷升级与允许后移

| 类型 | 定义 | 默认处理 |
|---|---|---|
| A / 硬伤 | 核心因果断裂、决定性胜负不成立、能力明文越界、持续污染的事实链 | **立即阻断并修复**；写手不能自行降级 |
| B / 阅读体验实质风险 | 中段连续憋屈、主角降智感、关键承诺不兑现、严重节奏失衡 | **当前弧内修复**；防止再污染下一弧 |
| C / 局部瑕疵 | 不改变后续因果、重大信息与已兑现承诺的轻微时间/称谓/数值/措辞问题 | **记录后移到完本**，一旦被依赖则升级复核 |
| 合理留白 | 原文支持或可合理推导且不损读者体验 | **保留，不修**；须可核验的原文辩护 |

注意：严重程度与处理时机**是不同维度**。对同一主体的后续引用只能触发 `DEFERRED_CASCADE_RISK` 待查提示，不应无证据直接判定有错；真正影响关键因果的级联应升级为 A，而不固定为 B。

## 7. 验收指标与可证实边界

**工程**：兼容率（R2 回归测试结果）、关键路径通过率、误阻断/漏阻断、快照与 Diff 可信度、作者批准证据有效性、卷级边界正确性、恢复能力。

**创作**：前三章陌生读者是否愿意读第4章、人物性格与情感、爽点兑现、连续阅读体验、跨章/跨卷硬伤数、修订对文风的负面影响。

**效率**：总调用/Token、耗时、前置规划时间、复审轮次、逃逸错误造成的实际返工字数。不能仅以“减少审核调用次数”宣称节约60%。

**证据**：每次更新必须指出实际运行命令、测试输出或评审记录；未知则标“待验证”。作者同意“3B＋完本精修”是**产品原则批准**，不是小说具体蓝图的作者签字。

## 8. 风险与防误用

| 风险 | 防护 |
|---|---|
| 随意修改冻结核心或卷级因果 | 明确锚点、内容快照、版本哈希、批准证据、fail-closed 门禁 |
| 微小瑕疵积累成重大事实链错误 | 延期台账＋事实/依赖关联＋写前提示＋及时人工语义判断 |
| 过度审稿抹平小说鲜活度 | 保护优秀桥段、正反证据、非阻断修复可后移 |
| 过早取消逐章审稿导致漏检 | 显式实验开关、同条件 A/B，总成本核算 |
| 修改 R2 原项目或伪造授权 | 独立实验分支/项目、原凭据只读、作者批准真实来源核验 |
| 过早把 R3 实验当成质量证明 | 区分工程通过、文学候选、真实读者验证三个层级 |
